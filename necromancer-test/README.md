## 启动与操作

Godot打开本目录project.godot，F5运行scenes/Battle.tscn。顶部菜单选择14关或重开；亡灵法师技能独立入口。左上日志、左下详情、右下结束回合。

- 左键选中，再点同一单位取消（己方/敌方都支持）。默认右键移动；选择移动后左右键可选终点；攻击/瞬移左键目标。数字键按按钮顺序选择，Esc取消，取消按钮始终最后。
- 移动蓝色外边界，悬停目的格蓝底并即时显示费用；攻击红色外圈，悬停预览实际格。敌人攻击动画时目标格红底红边。
- WASD、中键拖动、鼠标贴边平移，镜头受地图边界限制。动画期间禁止战斗动作；友伤警告可确认并选择以后不再提示。
- 控制区红色外边界＋半透明填色，重叠加深；守护白色、战斗号令金黄色，持续可见；溃逃白旗、尸体灰字。
- 随机事件第4轮起每轮50%，本局最多一次；事件动画后弹窗，确认“继续战斗”再操作。

## 当前规则入口

- BattleEngine：动作校验、回合、路径、伤害、状态、死亡与尸体、亡灵法师技能。
- Terrain：高度/障碍与矛兵两格阻挡；ChargeRules/KnockbackRules：恰好3格冲锋、正前方单体4伤害、击退与坠落。
- MoraleRules/FleePaths：士气状态惩罚、尸体每具-20、2回合溃逃和完全包围重计时。
- RandomEvents：援兵、意外苏醒、灵魂暴走、魔力失控、魔力涌动，固定seed重放。
- AIController及策略：单步选择、集火、高地、支援作战单位；模型AI尚未接入。
- Battle/HexBoardView：HUD、输入、预览、动画、友伤和事件弹窗。

法师技能无次数限制：召唤僵尸20、血肉塑形20（最大HP+10并恢复10）、献祭0（当前HP等量恢复支配力、魂归主宰另+5）。指挥官号令6，破绽标记6；详细兵种动作见总览。
