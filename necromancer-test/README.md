# 亡灵法师战棋 MVP

当前六关、全部兵种及最新规则请先阅读[游戏设定与技术规则总览](../游戏设定与技术规则总览.md)。该文档同时说明实际技术实现和未来模型AI训练规划；本README下方保留部分早期迭代说明。

Godot 4.6 / GDScript。设计来源：上一级目录的 GDD_v1.0.md。

## 启动与操作

第三关可从顶部菜单选择，敌方为1矛兵+1弓兵+1盾兵，己方不变；重新开始会保留第三关。

顶部中央“菜单”可切换第一关、第二关；切换立即重新开局。第一关为2矛兵+1弓兵，第二关为2矛兵+1盾兵；己方均为1吸血鬼+2僵尸。重新开始保留当前关卡。关卡阵容配置位于 data/levels.json。

用 Godot 打开本目录的 project.godot，按 F5 运行项目。主场景是 scenes/Battle.tscn。采用 Compatibility 渲染，Windows 中文字体优先使用微软雅黑。

- 左键选择亡灵，立即显示可达范围；右键高亮空格自动寻路。
- 移动时分别绘制每名敌方近战单位控制区的最外侧红色高光轮廓，不描内部格线。重叠区域保留各自边界，所有边界及单位圆环统一使用同一种红色；蓝色底色仍表示可达。进入范围不触发，从范围内继续移动或离开才触发；瞬移不显示此提示。
- 点击“移动1格”后，左右键均可选择终点，实际按完整路径逐格收费。
- 点击攻击或瞬移按钮，再左键选择目标。攻击可以选择友军。
- 数字键按动作栏顺序选择（支持主键盘和小键盘）：1移动、2攻击；吸血鬼3瞬移、4取消，僵尸3取消。禁用动作不能通过快捷键选择。
- Esc 或动作栏最后的“取消”返回默认移动高亮，不撤销已完成动作。
- WASD、中键拖动平移棋盘；右键用于移动。
- 右下角结束回合，人类依次行动；顶部菜单中的“重新开始”重开当前关卡，战斗结束后也可使用。
- AI在敌人进入攻击范围后通常停止移动：矛兵2格、弓兵5格。矛兵若攻击都会误伤友军，会预留3AP，尝试移动到不误伤的位置再攻击；无足够AP或可行站位才结束行动。每步重新观察。
- AI在单体攻击目标间优先选择当前HP数值更低的敌人（不是血量百分比）；范围攻击继续考虑多目标收益和友伤。
- 守护开启时持续显示白色范围外轮廓，未选中、攻击/瞬移模式和AI回合也可见；到期或死亡后消失。
- AI逐格移动后的等待为0.10秒（原0.38秒），攻击、受击等动画速度不变。
- 左键敌人可查看资料，不能控制敌人。

## 实现与配置

人类特性“众志成城”：攻击者每有一名相邻存活人类友军，每次造成的伤害增加1；普通攻击、借机攻击及范围伤害每次命中均适用。加成后进行守护转移，不重复加成，也不再减伤。亡灵特性“魂归主宰”：死亡恢复5支配力，上限20，每次死亡仅触发一次。专项测试：tests/test_traits.gd。

三关均加入中央台地示例。`data/terrain.json` 使用 `列,行` 键配置高度，未配置为0。同高步行1点，上下1级台阶2点，超过1级不可步行跨越；亡灵用支配力、人类用AP。瞬移不受高度限制，攻击与相邻范围仍按水平距离计算。加权寻路优先最低资源费用，同费用优先少借机攻击；AI可绕过落差寻找攻击位置。地表抬高、岩壁侧面和层线表示高度，数字辅助识别，点击匹配抬高后的地表。专项测试：`tests/test_terrain.gd`。

- scripts/core/BattleEngine.gd：独立于场景的状态、规则、合法动作、资源、事件、寻路与伤害结算。
- scripts/core/HexGrid.gd：axial 逻辑、odd-r 布局与点击转换。
- scripts/ai/AIController.gd 和 HeuristicPolicy.gd：choose_action(observation, legal_actions) 单步决策。
- scripts/ui/Battle.gd：界面、输入状态、AI执行节奏；HexBoardView.gd 绘制棋盘和文字单位。
- data/units.json：单位数值与攻击形状。
- data/battle_setup.json：初始部署、随机种子及采用的结算顺序说明。

多个借机攻击按部署顺序结算，每次出手前检查存活。借机攻击只伤害敌方，矛兵穿刺会跳过友军，但仍可命中范围内的多个敌人；主动攻击仍允许友伤。矛兵穿刺按近格到远格结算，每个目标独立随机伤害，每次伤害后检查胜负并立即停止已结束战斗的后续结算。

普通移动无6格限制，按资源和最短路径计算；6格限制仅属于瞬移。同长度路径优先选择预计借机攻击次数少的路线。高亮表示路径与资源合法，不保证经过危险区域后存活。

状态观测包含地图、单位、资源、控制区和合法动作，可 JSON 序列化。通过相同配置、seed 和 action_history 从开局重放；rng_state 以字符串保存以免 JSON 精度丢失。本期不包含模型训练或任意中途快照导入。

## 测试

将 godot 替换为本机 Godot 可执行文件路径：

```powershell
godot --headless --path . --script res://tests/run_tests.gd
godot --path . --script res://tests/test_ui.gd
```

规则测试涵盖六边形、资源回合、移动阻挡、控制区、友伤、瞬移、死亡、AI、完整战斗与种子重放。UI测试模拟输入检查选中、左右键移动、取消、UI拦截和重开，并生成 tests/battle_preview.png。

部署与种子为可修改默认配置。AI是临时简单策略，未经难度和平衡调优。移动位置即时更新；攻击有抬起、下砸、回位动作，受击会抖动、闪红并显示伤害数字。动画按事件顺序播放，期间可以平移镜头，不能下达新战斗动作。

盾兵：20HP、6AP，盾击3AP造成1–2伤害（范围1）；守护3AP，保护相邻6格至下次人类回合开始。友军受击免伤并闪白光，盾兵承担整份伤害；范围命中自己与友军则分别承担。开启守护的盾兵互不保护，未开启的可以被保护，多守护按部署顺序仅转移一次。AI会主动守护受威胁的邻近友军。专项测试：godot --headless --path . --script res://tests/test_guard.gd。

盾兵开启守护后优先移动以覆盖更多盟友，按当前AP内可达位置评估，每步重新观察；不能增加覆盖时才考虑原地攻击，不为追击放弃守护站位。
