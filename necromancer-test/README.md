# 亡灵法师战棋 MVP

Godot 4.6 / GDScript。设计来源：上一级目录的 GDD_v1.0.md。

## 启动与操作

用 Godot 打开本目录的 project.godot，按 F5 运行项目。主场景是 scenes/Battle.tscn。采用 Compatibility 渲染，Windows 中文字体优先使用微软雅黑。

- 左键选择亡灵，立即显示可达范围；右键高亮空格自动寻路。
- 移动时红框标记敌方借机攻击范围，蓝色底色仍表示可达。走入红框不触发，从红框格继续移动或离开才触发；瞬移不显示此提示。
- 点击“移动1格”后，左右键均可选择终点，实际按完整路径逐格收费。
- 点击攻击或瞬移按钮，再左键选择目标。攻击可以选择友军。
- 数字键按动作栏顺序选择（支持主键盘和小键盘）：1移动、2攻击；吸血鬼3瞬移、4取消，僵尸3取消。禁用动作不能通过快捷键选择。
- Esc 或动作栏最后的“取消”返回默认移动高亮，不撤销已完成动作。
- WASD、中键拖动平移棋盘；右键用于移动。
- 右上角结束回合，人类依次行动；战斗结束后可以重新开始。
- AI在敌人进入攻击范围后停止移动：矛兵2格、弓兵5格；无法进行合适的攻击时结束行动，不继续贴近。
- AI在单体攻击目标间优先选择当前HP数值更低的敌人（不是血量百分比）；范围攻击继续考虑多目标收益和友伤。
- 左键敌人可查看资料，不能控制敌人。

## 实现与配置

- scripts/core/BattleEngine.gd：独立于场景的状态、规则、合法动作、资源、事件、寻路与伤害结算。
- scripts/core/HexGrid.gd：axial 逻辑、odd-r 布局与点击转换。
- scripts/ai/AIController.gd 和 HeuristicPolicy.gd：choose_action(observation, legal_actions) 单步决策。
- scripts/ui/Battle.gd：界面、输入状态、AI执行节奏；HexBoardView.gd 绘制棋盘和文字单位。
- data/units.json：单位数值与攻击形状。
- data/battle_setup.json：初始部署、随机种子及采用的结算顺序说明。

多个借机攻击按部署顺序结算，每次出手前检查存活。矛兵穿刺按近格到远格结算，每个目标独立随机伤害，每次伤害后检查胜负并立即停止已结束战斗的后续结算。

普通移动无6格限制，按资源和最短路径计算；6格限制仅属于瞬移。同长度路径优先选择预计借机攻击次数少的路线。高亮表示路径与资源合法，不保证经过危险区域后存活。

状态观测包含地图、单位、资源、控制区和合法动作，可 JSON 序列化。通过相同配置、seed 和 action_history 从开局重放；rng_state 以字符串保存以免 JSON 精度丢失。本期不包含模型训练或任意中途快照导入。

## 测试

将 godot 替换为本机 Godot 可执行文件路径：

```powershell
godot --headless --path . --script res://tests/run_tests.gd
godot --path . --script res://tests/test_ui.gd
```

规则测试涵盖六边形、资源回合、移动阻挡、控制区、友伤、瞬移、死亡、AI、完整战斗与种子重放。UI测试模拟输入检查选中、左右键移动、取消、UI拦截和重开，并生成 tests/battle_preview.png。

部署与种子为可修改默认配置。AI是临时简单策略，未经难度和平衡调优。移动位置即时更新；攻击有抬起、下砸、回位动作，受击会抖动、闪红并显示伤害数字。动画按事件顺序播放，期间可以平移镜头，不能下达新战斗动作。
